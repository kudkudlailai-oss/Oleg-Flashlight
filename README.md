**Oleg Flashlight**

A Fabric mod for Minecraft 26.2. It adds a flashlight with a real spotlight and an infinite battery, and you spawn with one.

**Building**
Install Java 25, then run `.\gradlew build` (Windows) or `./gradlew build` (Mac/Linux) in the project folder. The jar is created in `build/libs`.

**Credits**
A port of the flashlight from [Backrooms: Found Footage](https://modrinth.com/mod/minecraft-found-footage) by SpacePotatoee.
